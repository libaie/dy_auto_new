第一个问题：模型类型怎么划分？

每种模型类型有专属参数集。这里是我根据现有业务规划的 5 种类型，参数是否合理？

脚本生成 (LLM)
用途: 剧本、分镜脚本、对话、提示词
字段:
• provider — deepseek / openai / anthropic / custom
• base_url — API 端点
• api_key — 密钥 (加密存储)
• model_name — deepseek-chat / gpt-4o
• thinking_enabled — 深度思考开关
• thinking_budget — token 上限
• max_tokens — 最大输出
• temperature — 创意度 0-2
画面生成 (Image)
用途: 分镜画面、角色立绘、场景图
字段:
• provider — seedance / openai / comfyui / runninghub
• base_url — API 端点 (非必填)
• api_key — 密钥
• model_name — dall-e-3 / flux / sdxl
• default_size — 如 1024x1024
• default_quality — standard / hd
你说不需考虑成本 → 不加 cost/price 字段
视频渲染 (Video)
用途: 视频生成、Seedance/Kling/Wan
字段:
• provider — seedance / kling / wan / pixelle
• api_key — 密钥
• api_secret — 签名密钥 (Kling 双钥)
• model_name — doubao-seedance-2.0
• default_resolution — 720p / 1080p
• default_duration — 5s / 10s
• default_aspect_ratio — 9:16 / 16:9
语音合成 (TTS)
用途: 旁白配音、角色配音
字段:
• provider — edge-tts / index-tts / spark-tts / custom
• base_url — API 端点 (非必填)
• api_key — 密钥 (非必填)
• model_name — edge-tts / index-tts
• default_voice — 默认音色 ID
• default_language — zh-CN / en-US
• default_speed — 语速 0.5-2.0
质量审计 (Audit)
用途: 生成后内容审核、画面质量检查
字段:
• provider — openai / gemini / local / none
• base_url — API 端点
• api_key — 密钥
• model_name — gpt-4o / gemini-2.5-pro
• audit_mode — multi (多模型投票) / single (单模型) / batch (批量)

这 5 种类型的划分和参数是否合理？
