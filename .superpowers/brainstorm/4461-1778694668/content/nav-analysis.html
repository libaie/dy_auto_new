第一个问题：归纳的主要目的是？

帮我对齐优先级，避免返工

A

纯视觉归纳 — 加分组标题，不改结构

在现有 20 项中插入 4-5 个分组标题分隔线，折叠/展开可选。代码改动量最小，只动 navigation.js 常量结构 + AppSidebar.vue 渲染。

B

二级菜单 — 组默认折叠，点击展开

每组折叠为一级标题，hover/click 展开子项。类似文件管理器侧边栏。减少视觉噪音，但需要额外状态管理和交互逻辑。

C

TopNav 分类 + 侧边栏上下文切换

TopNav 放 4-5 个分类入口，侧边栏只显示当前分类的子导航。类似 VS Code 活动栏 + 侧边栏模式。适合跨模块频繁切换的场景。
